You need Factorio 2.0.73 with Space Age (for elevated rails) and Windows.

  1. Download and open the companion.
    Download Windows companion
    It detects your Factorio account name and saves its own reporting access automatically. If you have several installations, choose the data folder used by your game. No JSON download or host approval.
  2. Install the bundled adaptive mod once.
    With Factorio closed, use Install bundled adaptive mod in the companion. This supplies our small custom mod; no Mod Portal download is needed. Repeating it safely reports “already installed.”
  3. Start Factorio and connect yourself.
    Use Copy address in the companion, then Factorio’s Multiplayer → Connect to address. Accept mod sync and restart if prompted. The first download is large. Keep the companion open; it changes from “Waiting” to “Connected — reporting simulation steps.”
Why keep it open? Every client simulates the whole factory. If yours processes fewer simulation steps per second than the server, queued steps build up and you fall behind. The companion reports checkpoint timing so the server can slow down before that queue becomes unmanageable.
Why both a mod and a companion? What is sent?

The mod writes a tiny local file when your simulation processes a server checkpoint. The companion watches that file and acknowledges its marker over HTTPS. The controller times the round trip on the server. This includes network delay and queued simulation work; it estimates delay, not the exact in-game buffer counter.

Factorio’s Lua mods cannot make ordinary HTTPS requests. Their code runs inside the shared simulation; the companion reports when your particular computer actually processes a marker. Optional localhost Lua UDP still needs an external program and a special game flag. Reading the marker file needs no launch flags.

The companion sends your account name, marker session and sequence number, plus its own reporting credential. It extracts your name from player-data.json but never sends your Factorio sign-in token. No research progress, inventory or save file is uploaded.

Waiting, slow speed, or the wrong folder?

“Waiting” is normal before joining. If it persists in-game, choose the correct data folder: usually %APPDATA%\Factorio for Steam, or your portable installation’s data folder. It contains mods and script-output.

The target range is 15–60 UPS; actual speed depends on the server and connected computers. The companion shows measured speed, target speed, delayed or missing reports, and a conditional countdown before an increase. Slow reports can come from a client backlog, network delay, or a stopped companion. A player unable to sustain 15 UPS needs a lower server minimum.
